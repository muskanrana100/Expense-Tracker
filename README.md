A modern expense management application built using React.js.

##  Features

- Add new expenses
- Delete expenses
- Edit expenses
- Track spending categories
- Manage transaction history
- Responsive UI

##  Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Vercel
